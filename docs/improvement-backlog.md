# Harness improvement backlog

This document records proposals to evolve `codex-harness`, including decisions and implementation evidence when available. It is separate from the approved [harness design](codex-native-sdd-harness-adaptation.md) and the per-project feature queue in `template/harness/features.json`.

A proposal is not an approval, and an approval is not evidence that a change was implemented.
