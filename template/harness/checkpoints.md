# Harness checkpoints

- [ ] Configuration and feature state pass `harnessctl validate`.
- [ ] At most one feature is `in_progress`.
- [ ] Every active non-legacy SDD feature has all three spec files.
- [ ] The approved spec digest is current.
- [ ] Every implementation task is checked.
- [ ] Every requirement has concrete test or verification evidence.
- [ ] Configured verification is successful and fingerprint-current.
- [ ] An independent review approves the current implementation fingerprint.
- [ ] Progress/history artifacts match the final state.
- [ ] No unrelated work, debug files, credentials, automatic push, or publication.
